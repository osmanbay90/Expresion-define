# English Expressions Learning Website

A modern web application for learning English expressions from Coach Shane's YouTube channel. The website uses the Gemini API to provide definitions and examples for each expression.

## Features

- Browse expressions by categories
- Search functionality
- Detailed explanations with examples
- Modern, responsive design
- Mobile-friendly interface

## How to Use

1. Open `index.html` in your web browser
2. Browse expressions by clicking on category buttons in the sidebar
3. Use the search bar to find specific expressions
4. Click on any expression card to see its detailed explanation and example
5. The explanation and example are generated using the Gemini API

The expressions are organized into the following categories:
- Common Greetings
- Work & Career

- Sports & Activities

- Food & Drink
- Emotions & Feelings

- Education & Learning
- Business & Work
- Home & Living
- Entertainment
- Health & Fitness

- Other Common Expressions

## Technical Details

- Built with HTML5, CSS3, and JavaScript
- Uses Bootstrap 5 for responsive design
- Integrates with Google's Gemini API for generating explanations
- No backend required - runs entirely in the browser

## Note

The website uses the Gemini API key provided in the code. For production use, it's recommended to:
1. Move the API key to a secure environment
2. Implement proper API key management
3. Add rate limiting and error handling
